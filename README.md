# DESARROLLO-DE-APLICACIONES-WEB-D-

## Proyecto Web GIRLS

Aplicación web desarrollada con **Flask** para la gestión de productos y proveedores de la tienda GIRLS.

### Tecnologías utilizadas

* Python
* Flask
* Flask-WTF
* Flask-Login
* PostgreSQL
* MySQL
* HTML
* CSS
* Bootstrap
* GitHub
* Render

### Funcionalidades

* Inicio de sesión y cierre de sesión.
* Registro de usuarios.
* Gestión de productos.
* Gestión de proveedores.
* Crear, consultar, modificar y eliminar registros.
* Relación entre las tablas mediante claves primarias y foráneas.
* Consulta de información relacionada mediante `JOIN`.
* Validación de formularios.
* Protección de las páginas mediante autenticación.

### Base de datos

El proyecto utiliza **PostgreSQL** en el entorno de producción y **MySQL** para el desarrollo local.

Las principales tablas utilizadas son:

* `usuarios`
* `proveedores`
* `productos`

La tabla `productos` se relaciona con `usuarios` y `proveedores` mediante claves foráneas.
